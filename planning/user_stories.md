# User Stories

## Outline User Roles
- **Visitor** – someone exploring the site before signing up  
- **Member** – a registered user who creates and follows personalized workout plans  
- **Admin** – manages content, verifies workout data, and ensures the platform remains safe and accurate  

---

## Draft User Stories

1. As a **visitor**, I want to learn about the platform’s purpose so that I can understand how it helps me reach my fitness goals.  

2. As a **visitor**, I want to create an account so that I can receive personalized workout recommendations.  

3. As a **visitor**, I want to browse sample workout plans so that I can see what kind of content is available before signing up.  

4. As a **member**, I want to input my height, weight, and fitness level so that the app can generate a plan suited to my body and ability.  

5. As a **member**, I want to update my personal information anytime so that my workout plan stays relevant as my fitness improves.  

6. As a **member**, I want to track my completed workouts so that I can measure my progress over time.  

7. As a **member**, I want to view progress charts and statistics so that I can stay motivated and monitor my performance visually.  

8. As a **member**, I want to set specific goals like “build muscle” or “lose weight” so that my workout plan aligns with my personal objectives.  

9. As a **member**, I want to participate in a community forum so that I can share tips, progress, and encouragement with others.  

10. As an **admin**, I want to review and manage forum content so that the community stays respectful and on-topic.  

11. As an **admin**, I want to verify the accuracy of workout data so that users only see professional and safe routines.
